# workflow-ui

React + TypeScript + Vite + MUI frontend for the workflow/routing module. See the
[repo root README](../../README.md) for how to run the full stack, demo logins, and the golden-path
walkthrough.

Quick reference:

```bash
npm install
npm run dev      # dev server on :5173, proxies /api to localhost:8090
npm run build
npm run lint
npm run seed      # creates a demo process template via the running backend
npm run e2e       # Playwright, needs the full docker-compose stack running
```
